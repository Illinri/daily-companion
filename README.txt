Daily Companion — Setup Guide
==============================

Requirements:
  - Python 3.10+ installed (https://python.org)
  - Make sure "Add Python to PATH" was checked during install

Steps:
  1. Open PowerShell or Command Prompt in this folder
  2. Run:   pip install customtkinter pillow
  3. Run:   python main.py

That's it! The app will open.

Tips:
  - Click the 📌 pin icon (bottom of sidebar) to keep the window always on top
  - Your data is saved locally in data.db (same folder as main.py)
  - You can resize the window freely
